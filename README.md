# 30분 3D 브랜드 웹사이트 스타터

댓글로 고른 업종을 바탕으로 Aside가 브랜드 조사를 정리하고, Codex가 그 결과를 이미 만들어진 3D 웹사이트에 적용하는 실습입니다. 3D 장면과 스크롤·마우스 모션은 완성되어 있으므로 수강생은 브랜드 정보 교체에 집중합니다.

## 실행하기

터미널에서 이 폴더를 연 뒤 아래 명령을 차례대로 실행합니다.

```bash
npm install
npm run dev
```

화면에 표시된 로컬 주소를 브라우저에서 엽니다.

## 실습 순서

1. 댓글에서 웹사이트로 표현하기 좋은 업종 하나를 고릅니다.
2. `prompts/01-aside-research.md`의 프롬프트를 Aside에 넣어 `research.md`와 `site-brief.json`을 만듭니다.
3. 두 파일을 이 폴더에 넣습니다.
4. `prompts/02-codex-apply.md`의 프롬프트를 Codex에 넣습니다.
5. 새 브랜드명, 색상, 프로젝트 3개와 3D·스크롤 효과를 확인합니다.

## 30분 진행표

- 0~5분: 댓글로 업종 선정, 완성 화면 확인
- 5~15분: Aside로 경쟁 브랜드 3곳 조사와 사이트 브리프 작성
- 15~25분: Codex로 브리프 적용, 화면 확인
- 25~30분: 결과 비교, 막힌 부분 복구, 질문

배포는 이 30분 실습에 넣지 않습니다. 로컬에서 브랜드가 바뀌고 상호작용이 유지되면 완료입니다.

## 공통 점검 지점

- 시작: 첫 화면에 `FORMA`가 보이고 마우스를 움직이면 3D 오브젝트가 반응합니다.
- 중간: `site-brief.json`에 새 브랜드와 프로젝트 3개가 있습니다.
- 완료: 첫 화면, 색상, 프로젝트 3개가 새 브랜드로 바뀌고 빌드가 통과합니다.

## 막혔을 때

- 화면이 열리지 않으면 `npm install`이 끝났는지 확인한 뒤 `npm run dev`를 다시 실행합니다.
- 수정 뒤 빈 화면이 나오면 `src/brand.js`의 따옴표와 쉼표를 먼저 확인합니다.
- 빠르게 처음 상태로 돌아가려면 `samples/brand.default.js` 내용을 `src/brand.js`에 다시 적용합니다.
- 3D가 표시되지 않아도 아래 프로젝트와 브랜드 소개가 보이면 텍스트 적용 결과는 확인할 수 있습니다.

## 파일 역할

- `src/brand.js`: 실습에서 바꾸는 브랜드 정보
- `site-brief.json`: Aside가 만든 결과를 놓는 자리
- `src/scene.js`: 완성된 3D 장면 — 실습에서는 수정하지 않음
- `src/style.css`: 완성된 레이아웃과 모션 — 실습에서는 수정하지 않음
- `samples/brand.default.js`: 복구용 기본 브랜드
